# Superstore Sales Analysis Project



###### *This project analyses the Sample Superstore dataset using Excel, SQL, and Python.*

###### *It includes data cleaning, exploratory data analysis, dashboard creation, and*

###### *Business insights.*





## **📌Project Overview**



###### *The goal of this project is to understand sales performance, profit trends, and*

###### *Customer behavior using the Superstore dataset.*



#### The project is divided into three parts.

* ###### *Excel Dashboard for interactive reporting*
* ###### *SQL Analysis for querying and aggregating data*
* ###### *Python Analysis for data exploration and visualization*





## **🎯Objectives**

* ###### *Analyze total sales and profit.*
* ###### *Identify top-performing categories and sub-categories.*
* ###### *Find loss-making products and regions.*
* ###### *Build an interactive Excel dashboard.*
* ###### *Practice SQL queries and Python data analysis.*

* ###### *West region contributed significant profit.*
* ###### *High discounts often reduced profitability.*
